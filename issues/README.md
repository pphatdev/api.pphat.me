# Issue Templates & Local Specs

This directory contains issue template drafts and local specification templates for `api.pphat.me`.

## 📁 Available Templates

- [01-bug-report.md](01-bug-report.md) - Standard template for bug reports.
- [02-feature-request.md](02-feature-request.md) - Standard template for new API endpoints or features.
- [03-task-chore.md](03-task-chore.md) - Template for internal maintenance, refactoring, and documentation updates.
- [04-security-vulnerability.md](04-security-vulnerability.md) - Guidance & template for reporting security issues privately.

> Note: GitHub web interface issue templates are located in [.github/ISSUE_TEMPLATE](../.github/ISSUE_TEMPLATE).
